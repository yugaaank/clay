# Support

## Before asking

Read:

- [`README.md`](README.md) for the project scope and quick start.
- [`docs/getting-started.md`](docs/getting-started.md) for installation,
  project generation, API examples, and troubleshooting.
- The generated application's `README.md` for CLI and lockfile behavior.

Search existing GitHub issues before opening a new one. Include the exact
command, operating system, Rust version, and relevant error output when asking
for help.

## Where to ask

- Usage questions and API discussions should use GitHub Discussions when that
  feature is enabled for the repository. Until then, open a clearly titled
  issue only when the question cannot be answered from the documentation.
- Reproducible broken behavior belongs in a
  [bug report](https://github.com/yugaaank/clay/issues/new?template=bug_report.yml).
- Proposed capabilities belong in a
  [feature request](https://github.com/yugaaank/clay/issues/new?template=feature_request.yml).
- Security vulnerabilities must not be posted publicly; follow
  [`SECURITY.md`](SECURITY.md).

Please do not use issues for private credentials, exploit details, or large
unrelated support requests.
